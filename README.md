# 🛡️ 灾害应急指挥与救援资源调度平台

基于 **Vue 3 + Vite + 高德地图 JS API v2.0** 的应急指挥演示系统。

## 功能特性

- **高德地图核心交互**
  - 受灾范围叠加（`Polygon`）、事件覆盖物（`Marker` 脉冲气泡）、人口密度热力图层（`Heatmap`）
  - 多类事件（洪涝/地震/火灾/山体滑坡/台风）按严重等级区分样式
  - 内建地图控件（缩放/比例尺/鹰眼）
- **事件管理**：搜索、类型/等级/状态筛选、事件详情、处置状态流转、处置时间线
- **资源调度**：多个资源库/救援点库存，拖拽式派发物资到受灾点，自动在地图绘制派发路线、估算距离与到达时间（直线 × 路网折算的演示算法）
- **多灾点资源统筹**
  - 按 灾情等级 → 需求缺口 → 运输时长 自动生成跨基地分配方案（预占不扣库存）
  - 方案支持人工调整（改数量 / 换基地自动重算时长），冲突项实时高亮
  - 提交时统一校验并锁定库存，库存冲突自动按运输时长重新分配，仍不足的缺口如实反馈
  - 批量派发联动更新事件状态与时间线、地图路线、大屏统计；需求清单实时显示 已派/需求 进度
- **群众转移安置**
  - 围绕灾情事件建立转移批次，指挥员分配车辆（占用资源库车辆库存）与安置点（预占床位）
  - 现场三环节登记：接运 → 入住 → 转出，支持单人（姓名/证件号）与批量两种模式
  - 重复登记检测：本批次重复直接拦截；跨批次重复可一键「改派」人员；批次级支持改派安置点/车辆
  - 床位容量联动：入住校验剩余床位（本批次预占自动释放），超容量提示改派
  - 安置点物资需求按在住人数 × 人均系数自动核算，一键就近调拨补给（生成补给派发记录）
  - 全部转出自动办结并回收车辆；进度实时回写事件详情、处置时间线与指挥大屏统计
- **指挥大屏**：在报事件、等级分布、今日派发、在途转移、安置中、受影响群众等实时统计，支持「实时模拟」自动刷新数据
- **多灾情场景**：预置多种 mock 场景（典型洪涝、汛期多点并发），一键切换

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 准备高德 key —— 复制样板文件为 .env 并填入自己的 key
copy .env.example .env
#   编辑 .env：
#   VITE_AMAP_KEY=你自己的高德key
#   （可选）VITE_AMAP_SECURITY_CODE=你的jscode安全密钥

# 3. 启动开发服务器
npm run dev
# 打开 http://localhost:5173
```

> 仓库已通过 `.gitignore` 忽略 `.env`，key 不会进入版本库。`.env.example` 为公开样板。

## 项目结构

```
disaster-command/
├── .env.example          # 环境变量样板（git 提交）
├── .gitignore            # 忽略 node_modules / .env / dist 等
├── vite.config.js
├── index.html
└── src/
    ├── main.js           # 入口
    ├── App.vue           # 三栏布局（事件 / 地图 / 调度+详情）
    ├── style.css
    ├── config/
    │   └── amap.js       # 高德 Loader 封装 + 读 .env key
    ├── mock/
    │   └── data.js       # 灾情场景 / 事件 / 资源库 / 安置点 mock 数据
    ├── store/
    │   ├── command.js    # Pinia 全局状态、派发与流转逻辑
    │   └── transfer.js   # 转移安置：批次、登记、床位与物资联动
    └── components/
        ├── CommandHeader.vue   # 顶栏 + 场景切换 + 大屏统计
        ├── EventList.vue       # 左侧事件列表 + 筛选
        ├── MapBoard.vue        # 高德地图渲染层（Polygon/Heatmap/Marker/路线/安置点）
        ├── DispatchPanel.vue   # 资源调度面板（单点派发 / 统筹方案 / 转移安置页签）
        ├── PlanPanel.vue       # 多灾点统筹：方案生成、人工调整、批量派发
        ├── TransferPanel.vue   # 转移安置：批次建派、接运/入住/转出登记、安置点补给
        └── EventDetail.vue     # 事件详情 + 状态流转 + 转移进度 + 时间线
```

## ⚠️ 安全提示

高德 key 直接写在前端 `.env` 中构建进产物，是**公开可见**的，且有每日调用配额。
- 仅适合本地开发 / 个人演示。
- 部署到生产或公开服务前，请替换为**限定域名**的正式 key，或通过**服务端代理**调用 Web 服务 API。
- 切勿将 `.env` 提交到公开仓库。
